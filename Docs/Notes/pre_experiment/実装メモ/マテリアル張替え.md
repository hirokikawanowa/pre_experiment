# BlenderからUnityでマテリアル・テクスチャを正しく再現する手順

## 1. Blender側でモデル作成
3Dモデルにマテリアル（色・質感）やテクスチャ画像（.png/.jpgなど）を設定します。

## 2. 画像テクスチャの確認・エクスポート
- Blenderで使っているテクスチャ画像が「外部ファイル（.pngや.jpg）」として存在しているか確認します。
- Blenderファイル内にテクスチャが「パック」されている場合は、「アンパック（Unpack）」して物理ファイルとして書き出す必要があります。
    - **手順**：画像ノードの横にある本のアイコンをクリック → 「Unpack」を選択 → 「Write file to current directory」などで保存します。
- 必要な画像ファイル（カラー、ノーマル、ORMなど）がPC上に揃っているか確認します。

## 3. BlenderからFBXでエクスポート
`ファイル` → `エクスポート` → `FBX (.fbx)` を選択します。
（推奨設定：メッシュ・マテリアルをON、テクスチャの自動コピーも便利です）

## 4. Unityにインポート
- 作成したFBXファイル
- テクスチャ画像（.png/.jpg）
これらをUnityプロジェクトの`Assets`フォルダ内にドラッグ＆ドロップします。

## 5. UnityでFBXからマテリアルを抽出
1. ProjectウィンドウでインポートしたFBXファイル（例：`location2`）を選択します。
2. Inspectorで`Materials`タブを開きます。
3. `Extract Materials...` ボタンを押します。
4. 保存先のフォルダ（例：`Assets/Materials`）を指定します。
5. これで、編集可能なマテリアル（球体のアイコン）がProject内に生成されます。

## 6. Unityのマテリアルにテクスチャを割り当てる
1. Projectウィンドウで抽出したマテリアル本体を選択し、Inspectorで編集します。
2. **Base Map**欄に、カラー用のテクスチャ画像をドラッグ＆ドロップします。
3. **Normal Map**欄に、ノーマルマップ用のテクスチャ画像をドラッグ＆ドロップします。（「Fix now」の警告が出たらクリックします）
4. **Metallic/Mask**欄などに、必要に応じてORMテクスチャなどを設定します。

## 7. マテリアルをオブジェクトに適用
シーン内のモデルを選択し、`Mesh Renderer`コンポーネントの`Materials`欄に、編集したマテリアルをドラッグ＆ドロップで適用します。
意図した通りの見た目になっているか確認してください。

---

## 補足
- FBXファイル内のサブアセット状態のマテリアルは直接編集できません。必ず`Extract Materials`で抽出してから編集してください。
- BlenderとUnityでテクスチャの命名規則を揃えておくと、Unity側で自動的に割り当てられやすくなります。
- ノーマルマップ用のテクスチャは、Inspectorで`Texture Type`が`Normal Map`に設定されていることを確認してください。

---

## 【最短まとめ】
1. **Blender**: モデルと画像テクスチャを用意し、必要ならアンパックして画像ファイルを保存。
2. **Unity**: FBXと画像ファイルを`Assets`にインポート。
3. **Unity**: FBXを選択し、Inspectorの`Materials`タブから`Extract Materials`を実行。
4. **Unity**: 抽出したマテリアルに各テクスチャを割り当てる。
5. **Unity**: モデルにマテリアルを適用して完成！
