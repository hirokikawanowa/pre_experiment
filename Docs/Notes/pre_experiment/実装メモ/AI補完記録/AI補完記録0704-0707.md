### 関連AI会話まとめ
- UnityアプリのログデータをGoogleフォーム経由で送信する方法について議論。
- Android端末でのログ取得の難しさから、Google Apps Script（GAS）を用いたデータ管理の容易化を提案。
- GASのスクリプト設定やUnityからのデータ送信手順を整理。
- ログ内容は「ロケーションの入退場時刻」「割り当てカードと順序」に限定し、不要なログはコメントアウト。
- ログ送信時にデータが空・不正となる問題が発生し、ログ取得・送信処理の見直しを実施。
- 必要なログのみが正しく記録・送信されるよう、Loggerや送信処理をリファクタリング。

### GAS実装詳細
1. **スプレッドシートの準備**
   - Googleドライブ上で新規Googleスプレッドシートを作成。
   - 必要なカラム（例：日時、ロケーション、カード情報など）を1行目に設定。

2. **GASスクリプトの作成**
   - スプレッドシートの「拡張機能」→「Apps Script」を開き、新規プロジェクトを作成。
   - 以下のようなdoPost関数を実装：
     ```javascript
     function doPost(e) {
       var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("シート名");
       var data = JSON.parse(e.postData.contents);
       sheet.appendRow([
         new Date(),
         data.location,
         data.card,
         data.order
         // 必要に応じて他の項目も追加
       ]);
       return ContentService.createTextOutput("success");
     }
     ```
   - セキュリティや複数人利用時の誤記録防止のため、`getActiveSheet()`ではなく`getSheetByName("シート名")`を推奨。

3. **Webアプリとして公開**
   - Apps Script画面で「デプロイ」→「新しいデプロイ」→「ウェブアプリ」選択。
   - 「自分」または「全員（匿名ユーザー含む）」にアクセス権を設定し、URLを発行。

4. **Unityからの送信例**
   - Unity側でHTTP POSTリクエストを作成し、GASのWebアプリURLにデータを送信。
   - 例（C#）：
     ```csharp
     using UnityEngine.Networking;
     // ...
     var json = JsonUtility.ToJson(logData);
     var request = new UnityWebRequest(gasUrl, "POST");
     byte[] bodyRaw = System.Text.Encoding.UTF8.GetBytes(json);
     request.uploadHandler = new UploadHandlerRaw(bodyRaw);
     request.downloadHandler = new DownloadHandlerBuffer();
     request.SetRequestHeader("Content-Type", "application/json");
     // ...
     ```

5. **注意点**
   - GAS側で受け取るデータ形式（JSON構造）とUnity側の送信内容が一致していることを確認。
   - スプレッドシートのシート名やカラム順が変更された場合、GASスクリプトも合わせて修正。
   - GASの無料枠には実行回数制限があるため、大量送信時は注意。

### UnityからGASへのデータ送信フロー
1. **Unity内でログデータを生成**
   - ゲーム進行やユーザー操作に応じて、必要な情報（例：ロケーション入退場時刻、カード情報など）をC#のクラスや構造体で保持。
   - 例：
     ```csharp
     [System.Serializable]
     public class LogData {
         public string location;
         public string card;
         public int order;
         // 他の必要な項目
     }
     ```

2. **データをJSON形式に変換**
   - Unityの`JsonUtility.ToJson()`などを使い、LogDataインスタンスをJSON文字列に変換。
   - 例：
     ```csharp
     var logData = new LogData { location = "Location1", card = "Apple", order = 1 };
     string json = JsonUtility.ToJson(logData);
     ```

3. **HTTP POSTリクエストでGASへ送信**
   - UnityWebRequestを使い、GASのWebアプリURLに対してPOSTリクエストを送信。
   - 例：
     ```csharp
     var request = new UnityWebRequest(gasUrl, "POST");
     byte[] bodyRaw = System.Text.Encoding.UTF8.GetBytes(json);
     request.uploadHandler = new UploadHandlerRaw(bodyRaw);
     request.downloadHandler = new DownloadHandlerBuffer();
     request.SetRequestHeader("Content-Type", "application/json");
     yield return request.SendWebRequest();
     if (request.result == UnityWebRequest.Result.Success) {
         Debug.Log("送信成功");
     } else {
         Debug.LogError("送信失敗: " + request.error);
     }
     ```

4. **GAS側でデータを受信・スプレッドシートに記録**
   - 送信されたJSONデータはGASのdoPost関数で受け取り、スプレッドシートにappendRowで記録。

5. **（オプション）Unityで送信結果を確認・UIに反映**
   - 送信成功/失敗に応じて、ユーザーに通知やUI更新を行うことも可能。

この流れにより、Unityで取得した任意のデータをリアルタイムでGoogleスプレッドシートに記録できます。
