## 2. スクリプトの実装

### 2.1 BaseRoomTemplate.cs
- 基本となる部屋のテンプレートクラス
- 壁、床、天井の生成機能
- 環境音の設定機能

### 2.2 JapaneseStudyTemplate.cs
- 和風書斎専用のテンプレートクラス
- 以下の要素を配置：
  - 畳（2x3の配置）
  - 障子
  - 文机
  - 掛け軸
- 環境音の設定：
  - 雨音（メイン）
  - 風鈴音
  - 庭の水音

## 3. アセットの準備

### 3.1 必要なアセット
1. 3Dモデル
   - 畳
   - 障子
   - 文机
   - 掛け軸

2. マテリアル
   - 壁用マテリアル
   - 床用マテリアル
   - 天井用マテリアル
   - 各オブジェクト用マテリアル

3. テクスチャ
   - 畳の模様
   - 障子の紙
   - 木目
   - その他装飾用テクスチャ

4. 音声
   - 雨音
   - 風鈴音
   - 庭の水音

### 3.2 アセットの仕様
- テクスチャ：2の累乗解像度（512x512, 1024x1024等）
- 3Dモデル：VR向けに最適化（適度なポリゴン数）
- 音声：ステレオ、192kbps程度

## 4. シーンの設定

### 4.1 Location_01.unity
- JapaneseStudyTemplateコンポーネントを持つGameObjectを配置
- 必要なアセットをInspectorで設定
- 部屋の基本設定（サイズ、マテリアル等）を調整
