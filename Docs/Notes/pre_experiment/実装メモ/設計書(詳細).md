# VRMoL システム設計書

## 1 システム概要

### 1.1 目的
VR空間内で記憶宮殿法を用いた記憶実験を行うためのシステムを構築する。

### 1.2 システム要件
1. 機能要件
   - 10の異なる空間をVRで再現
   - 空間オーディオと非空間オーディオの切り替え
   - 単語カードの配置と管理
   - 実験データの記録
   - 進行状況の表示

2. 非機能要件
   - パフォーマンス：72FPS以上を維持
   - 遅延：音声遅延50ms以下
   - 安定性：長時間の実験に耐えられる安定性
   - 拡張性：新しいロケーションの追加が容易
   - 保守性：コードの可読性と再利用性の確保

## 2 システム構成

### 2.1 ハードウェア要件
- **PC**：Windows 10/11、GPU RTX 3060 以上推奨  
- **HMD**：Meta Quest 3（Air Link／Meta Link どちらでも可）  
- **ヘッドホン**：AirPods Pro（Bluetooth・低遅延モード有効）  

### 2.2 ソフトウェア要件
- **Unity**：2021.3 LTS  
- **必須パッケージ**：
  - SteamVR Plugin 2.x  
  - Steam Audio (v4.6)  
  - Addressables  
  - Post-processing（URP 使用時は Volume）

## 3 詳細設計

### 3.1 ロケーション設計

#### 3.1.1 基本仕様
- 各ロケーションのサイズ：5m x 5m x 3m（統一）
- ドアの位置：各ロケーションの端に配置
- 照明：各ロケーションに適した色温度と強度
- コライダー：壁、床、天井、家具に適切に設定
- モデル作成：Blenderで各部屋の基本モデルを作成
  - ポリゴン数：10,000以下
  - テクスチャサイズ：2048x2048以下
  - UVマッピング：適切に設定
  - エクスポート形式：FBX
  - スケール：1:1（Unity基準）

#### 3.1.2 モデル最適化ガイドライン
- 静的バッチングのための適切なメッシュ分割
- LODの実装（3段階）
- コライダーの最適化
- テクスチャの圧縮設定
- マテリアルの最適化

### 3.2 音声システム設計

#### 3.2.1 音声仕様
- フォーマット：WAV 48kHz/16bit
- チャンネル：モノラル
- 長さ：環境音は1分ループ
- 音量：-28 LUFSに統一
