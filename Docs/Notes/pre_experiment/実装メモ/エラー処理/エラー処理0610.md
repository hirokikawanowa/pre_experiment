# VRシーンでの「動けない」「床をすり抜けて落下する」エラー対策まとめ（2024/06/10）

## 1. 症状
- VR空間で最初は見えるが動けない
- すぐに床を貫通して落下し続ける

## 2. 主な原因
- プレイヤー（カメラリグ）の初期位置が不適切
- 床オブジェクトにColliderが付いていない、または設定ミス
- プレイヤーリグのColliderやRigidbodyの設定ミス

## 3. チェックリスト
### 3.1 プレイヤーの初期位置
- Camera Offset（親オブジェクト）のY座標を1.3〜1.6程度に設定
- Main CameraのY座標は0のままでOK

### 3.2 床のCollider
- 床オブジェクト（例：Tatami_02）にBox ColliderやMesh Colliderを追加
- 「Is Trigger」はオフにする
- Mesh Colliderの場合はConvex推奨

### 3.3 プレイヤーリグのCollider/Rigidbody
- 足元にCapsule ColliderやCharacter Controllerを追加
- Rigidbodyがある場合は「Is Kinematic」ONまたは「Use Gravity」OFFを検討

## 4. よくあるミス
- 床にColliderが付いていない
- Colliderが「Is Trigger」になっている
- プレイヤーの初期位置が床より下や壁の中
- プレイヤーリグのColliderが未設定
