# tripo-mcp セットアップ・起動マニュアル

このマニュアルでは、`tripo-mcp` のセットアップおよび起動手順について説明します。

---

## 1. ディレクトリの移動

まず、`tripo-mcp` ディレクトリに移動します。

```sh
cd tripo-mcp/
```

---

## 2. 仮想環境の作成

`uv` を使って仮想環境を作成します。

```sh
uv venv
```

---

## 3. パッケージのインストール

`uv` を使って、`tripo-mcp` を開発モードでインストールします。

```sh
uv pip install -e .
```

---

## 4. サーバーの起動

`uvx` コマンドで `tripo-mcp` を起動します。

```sh
uvx tripo-mcp
```

---

## 補足
- `uv` や `uvx` がインストールされていない場合は、事前にインストールしてください。
- コマンドはPowerShellやターミナルで実行してください。
- エラーが発生した場合は、エラーメッセージを確認し、必要に応じて依存関係を追加してください。
