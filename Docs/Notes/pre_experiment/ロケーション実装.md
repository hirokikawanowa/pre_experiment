## Implementation Hints

- Create a single "House" scene.  For each room:
    - Duplicate 4×4×3 m cube prefab, apply wall/floor materials.
    - Place landmark prop at `center + landmark.local_pos`.
    - Add empty GameObject at `center + word_anchor.local_pos`.
      Attach AudioSource  (word clip runtime assign).
    - Add empty GameObject at room perimeter, tag "RoomTrigger",
      add BoxCollider (isTrigger) covering the room.
      OnTriggerEnter → GameManager.SetCurrentRoom(id).
- Ambient AudioSource sits at room center; Spatial Blend 1,
  minDistance 1 m, maxDistance 10 m.
- Word clips assigned on demand; Spatial Blend toggled 0/1.
- Corridor ceiling lights: baked, emission 5 cd, warm white.
- Light probes grid 2 m spacing for dynamic objects.
- Static batching ON for walls/floors; props LOD if >5k tris.
- Build target: Android (Quest), Graphics API Vulkan, Texture ASTC-6×6.
